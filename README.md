# School-projects

Archive of programming assignments, reports and course deliverables from my Bachelor's and Master's studies at UIT and NTNU.

This repository is a personal registry of coursework — code, reports, lecture notes and exam material — grouped by course code. It is intended for reference and archival purposes rather than as a single runnable project.

Structure
- Top-level folders are course codes (e.g. `Inf2200`, `Inf3201`, `Tdt4310`).
- Inside each course folder you will typically find assignment subfolders, reports (PDF/DOCX), source code (C, C++, Java, Python), lecture notes and any auxiliary data files.

Notes
- Some folders contain large binary files (PDF/DOCX/.db). Those are course deliverables or reports. If you want a slimmer repo later we can move them into a `docs/` archive or a release.
- Some course folders contain nested subfolders; explore inside each course folder to find the code and deliverables for each assignment.

If you want me to do any housekeeping (move large files to `docs/`, add per-course README templates, or open a PR with changes) tell me which action(s) and I will prepare them.
