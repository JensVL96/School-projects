# School Projects

Archive of programming assignments, reports, and course deliverables from my
Bachelor's and Master's studies at UiT (The Arctic University of Norway) and
NTNU.

A personal registry of coursework — code, reports, lecture notes, and exam
material — grouped by course code. Intended for reference and archival purposes
rather than as a single runnable project.

## Structure

- Top-level folders are course codes (e.g. `Inf2200`, `Inf3201`, `Tdt4310`),
  each with its own README describing the course and what's inside.
- Within a course folder you'll typically find assignment subfolders, reports
  (PDF/DOCX), source code (C, C++, Java, Python, Rust, Oz), lecture notes, and
  auxiliary data.

## Highlights

- **Master's thesis** — [How Prompts Affect Response Quality in LLM-Generated
  Programming Solutions](https://github.com/JensVL96/Code-Quality-Thesis) (UiT),
  in its own repository.
- Coursework spans systems (distributed systems, computer architecture,
  databases), graphics and game development, NLP and machine learning,
  software engineering, and empirical research methods.

## Notes

Some courses were taken across two attempts or resubmissions; where multiple
versions of a deliverable exist, they're kept intact to preserve the
development history rather than flattened.
