# AUT-2602 — Microcontroller Programming (UiT)

Coursework for UiT's Microcontroller Programming course: embedded C on Microchip
AVR microcontrollers using Microchip Studio (USART serial, ADC, PWM, RTC, CCL,
interrupt-driven I/O).

## Assignments

Five module assignments (`Aut2602_Assignment_1`–`5`) working through embedded C
on the AVR128DB: USART communication, ADC reading and filtering, PWM and timer
(TCA) configuration, interrupt/ISR handling, and register-level programming —
with code-comprehension, debugging, and implementation tasks.

*Embedded C · AVR microcontrollers · Microchip Studio · USART · interrupts ·
PWM/ADC · timers*
