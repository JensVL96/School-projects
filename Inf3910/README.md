# INF-3910 — Computer Science Seminar / GameLab

This folder contains the INF-3910 project material, including seminar deliverables, milestone reports, and the game project assets for the GameLab work.

## What this folder is for
The project documents the development of the seminar/GameLab work across multiple milestones, from early planning and design to the final report and supporting assets.

## Project focus
The material in this folder covers:
- milestone reports and reflection notes
- the final written report
- game project assets such as maps, design files, and presentation material
- supporting files used during the development process

## Structure
The folder is organized around the deliverables produced during the project, with reports and assets stored together so the full development history is easy to follow.
