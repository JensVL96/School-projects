# INF-3910 — Computer Science Seminar: GameLab (UiT)

Coursework for UiT's GameLab seminar — developing a game through a full
production pipeline across six milestones (high concept → design → prototype →
alpha → beta → live), with milestone reports, a reflection note, and a final
report.

## Project — "Mythos Grant" (Godot Fighting Game)

▶ **Play it:** https://rehunterg.itch.io/mythos-grant

*Mythos Grant* is a fast-paced 1v1 local-multiplayer fighting game built in
**Godot**, blending platforming with sword combat. The premise: rival
historians, armed with legendary sword relics, settle scholarly debates in a
tournament where the winning field of research takes the grant money. Released
on itch.io.

Built over the semester through the six-milestone game-dev pipeline, with
hands-on work in state machines, pixel art, sound, and music. Levels were made
with the Ogmo and Tiled map editors, and an early game jam fed into the design.
Graphics were AI-assisted (disclosed on the itch.io page).

*Game development · Godot · fighting-game design · local multiplayer · state
machines · pixel art · level design · production pipeline*

**Deliverables:** playable build on itch.io; `Final version.pdf` (final report),
`Milestone 2–5.pdf`, `Reflection Note.pdf`, `Mythos Grant.pptx` (design deck),
