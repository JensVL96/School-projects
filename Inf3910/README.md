# INF-3910 — Computer Science Seminar: GameLab (UiT)

Coursework for UiT's GameLab seminar — developing a game through a full
production pipeline across six milestones (high concept → design → prototype →
alpha → beta → live), with milestone reports, a reflection note, and a final
report.

## Project — "Mythos Grant" (Godot Pixel-Art Game)

A pixel-art game built solo in **Godot**, taken from concept to a playable
state over the semester. The written work documents each milestone: high
concept, design, prototype, alpha, beta, and live. Levels were built with the
Ogmo and Tiled map editors, and the project involved hands-on work with state
machines, pixel art, sound, and music. A game jam early in the course fed into
the design process.

*Game development · Godot · state machines · pixel art · level design · game
production pipeline · sound/music*

**Deliverables:** `Final version.pdf` (final report), `Milestone 2–5.pdf`,
`Reflection Note.pdf`, `Mythos Grant.pptx` (design deck), and map/asset files
(`.ogmo`, `.tiled-project`, `map1/2.json`).
