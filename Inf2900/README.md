# INF-2900 — Software Engineering (UiT)

Team-based software engineering project at UiT, run Agile (user stories,
iterative delivery, heavy testing) with a GitLab workflow — issue/merge-request
templates and CI. The deliverable is a Django web application.

## Project — Food Planner (Django Web App)

A meal-planning web app for managing ingredients, inventory, recipes, and a
shopping list, with user accounts. Built in **Django** with a modular app
structure (separate apps for ingredients, inventory, recipes, shopping list,
and users), server-rendered templates, and a substantial test suite spanning
unit tests, view/form tests, and Selenium-driven acceptance tests, wired into
GitLab CI.

*Software engineering · Agile · Django · Python · web development · unit &
acceptance testing · Selenium · CI/CD · team collaboration*

**Note:** `food_planner/` is the final version. `food_planner-html-templates/`
and `shopping_list/` are earlier development stages, kept for history.
