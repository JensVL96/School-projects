# INF-2900 — Web & Small Projects

This folder contains small web applications and front-end templates created for INF-2900 assignments.

Notable subfolders:
- `food_planner/` — full project for the food planner assignment
- `food_planner-html-templates/` — HTML templates
- `shopping_list/` — shopping list project
- `public/` — static assets

Notes:
- To preview HTML projects run `python3 -m http.server` from the project folder or open the HTML files directly in a browser.
