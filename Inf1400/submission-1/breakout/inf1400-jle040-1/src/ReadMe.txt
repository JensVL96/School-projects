
Flock simulation boids


made by Jens Christian Valen Leynse


This simulation is made using the same principles as the original flock simulator, 

written by Craig Reynolds in 1986.





RUN THE Simulation:



open the terminal and find the folder with the simulation files



run the command : python3 Boids.py





CONTROLS:



Scroll upwards on the mouse to add boids 



Scroll downwards on the mouse to add hoiks



Hold in right mouse button to add obstacles



Hold in the left mouse button to add bait (will be removed once button is released)



'esc' to exit the simulation 





DEPENDENCIES:



Pygame 1.9.2 (Python 3)
