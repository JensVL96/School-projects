
Mayhem simulator


made by Jens Christian Valen Leynse


This clone is a replica of Mayhem, a classic Amiga game





Description:



The goal of the game is to gain the most points. The way to do this is to
avoid obstacles, as crashing into it, the wall and the other player will
result in the player loosing points as a penalty. The way to gain points
is by shooting down the opponent. The player will also have to look out
for their fuel tank as an empty tank means no thrust. The player can 
keep their fuel up by flying into note sheets on the screen or by landing 
on the their own stand.





RUN THE Simulation:



open the terminal and find the folder with the simulation files


run the command : python3 Mayhem.py





CONTROLS:



Player 1:


Up key to thrust

Right control key to shoot

Left key to rotate left

Right key to rotate right



Player 2:


W key to thrust

Left control key to shoot

A key to rotate left

D key to rotate rights released)



'esc' to exit the game





DEPENDENCIES:



Pygame 1.9.2 (Python 3)
